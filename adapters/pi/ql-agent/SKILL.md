---
name: ql-agent-reading
description: Project an exact sourced event, inspect unresolved QL heads, validate a provider response or read computed harmonics with the native QL owner.
---

Use `ql_project_event` with the actual event/source revisions and only the semantic heads the concern warrants. Inspect the returned determination before seeking learned evidence. An empty `decision_head_ids` field requires no classifier call. Missing input remains missing input.

Use `ql_decision_frame` to inspect the owner-issued candidate field and constraints. Use `ql_validate_determination` with the original projection request and exact provider response; retain stale, unavailable and refused results. A provider answer never overrides observed coordinates.

Use `ql_decide` when the concern warrants semantic determination. It completes deterministic QL first and uses the shared QL/AIKit instrument only for remaining eligible heads. A provider is elected explicitly through `QL_AGENT_DECISION_CONFIG`; absent or unavailable execution remains legible. This explicit tool may take time, and is never an entry hook.

Use `ql_invoke` with an exact current faculty, native operation ref and the required typed input after inspecting the determination. The owner validates membership and computes the actual result. Missing operation input is not supplied by the classifier.

Use `ql_harmonic_read` to compute the musical rendering from the same formal event. Preserve the returned kernel and source basis. Native tools call the installed `ql-agent` or shared `ql-agent-decide` in the current session directory. `QL_AGENT_BIN` and `QL_AGENT_DECIDE_BIN` may supply managed instruments. All formal interpretation and operations stay in the native QL owner.

With `/ql-mode on`, an input beginning `QL state:` followed by a JSON object of supplied formal fields enters the shared owner projector asynchronously. For example: `QL state: {"lens":"L2'","local-position":3,"coordinate-face":"direct","musical-basis":"chromatic"}`. An input beginning `QL read:` followed by the concern requests the native faculty/operation candidate field. The hook never calls a classifier: inspect the retained frame, then request `ql_decide` only when warranted. Results become available to later turns; `/ql-status` reports a pending projection. Ordinary input starts no projector or classifier. A newer QL occasion, mode-off or session navigation cancels older pending work. `QL_AGENT_ENCOUNTER_BIN` may select the managed owner instrument.
