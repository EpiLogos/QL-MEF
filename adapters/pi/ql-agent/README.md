Install this package with Pi 0.84.4 using `pi install /absolute/path/to/adapters/pi/ql-agent`. Supply the current source-built QL executable through `QL_AGENT_BIN`, or use the installed `ql-agent` on PATH. The package contributes six native tools and one reading skill. Registration starts no provider or model.

The event schema is carried verbatim from the QL owner. All formal completion, candidate fields, admission and musical readings run through `ql agent-event`; tool responses retain the exact native JSON and its kernel/source basis. The extension bounds input, output, cancellation and process duration.

Use `/ql-mode on` to carry successful native QL tool receipts into the next agent turn, and `/ql-status` to inspect their body/session basis. `/ql-mode off` clears that context while preserving ordinary tools. Session, input, tool and compaction hooks retain bounded native occasion metadata. Hooks start no classifier; learned determination remains an explicit `ql_decide` operation. Prime composes this same owner extension through its installed faculty binding.

Mode recovery follows the active session branch. Tree navigation clears cached readings, and a superseded tool call cannot replace a newer reading. Embedded source/provider material remains explicitly untrusted data; its instructions are never native QL authority.

Explicit `QL state: {"lens":"L2'","local-position":3,"coordinate-face":"direct","musical-basis":"chromatic"}` and `QL read: <concern>` input carriers use the installed shared `ql-agent-encounter` instrument. It owns eligibility, source hashing and native projection. Input hooks launch it asynchronously and never wait for inference. A reading from a superseded occasion cannot enter continuation. Ordinary input and tool output containing those words do not acquire learned authority. The state carrier supplies observed fields; the read carrier retains unresolved native faculty/operation heads for an explicit warranted decision.

Run the explicit native integration gate after installing the pinned Pi SDK in the hosted environment:

```sh
AIKIT_PI_SDK_ROOT=/absolute/path/to/node_modules/@earendil-works/pi-coding-agent cargo test --locked -p ql-cli --test pi_agent_native -- --ignored --nocapture --test-threads=1
```

That gate uses native Pi argument validation and tool execution against the actual QL CLI. It checks deterministic bypass, unavailable admission, impossible observed-state refusal, real persistent homology, wrong-faculty refusal, cancellation and size bounds. It works with both the direct package and its AIKit SkillSet export. `tests/native-event-loop.mjs` and `tests/native-body-loop-cli.mjs` separately exercise actual agent turns, native tool events, continuation receipt context and mode-off continuation. Learned model performance requires its own evaluation.

For the AIKit route, register `adapters/pi` with `aikit system source add-directory ql-native-owner`, then sync and promote its exact snapshot. Create the `ql-native-agent` SkillSet with member `skill/ql-native-owner/ql-agent`, and copy this owner's `aikit-set.toml` to that set's `set.toml`. Export with `aikit set package export ql-native-agent --target pi --native`. The contributed module and its contract/provenance assets remain owned by this QL source payload.
