## 1. The product meaning this lane must implement

The Wiki makes existing linked writing and other native sources immediately useful without requiring QL. Markdown links, wikilinks, backlinks, tags and exact passages are part of the real source field, not incidental demo inputs. Over that field, humans and agents deliberately create, discover, edit and recombine contextual constellations.

Technè's creative body is the existing Expression system: three-dimensional composition, selectable glyphs, text and writing overlays, images, line and particle relations, physical material, actual Scenes and Palace compositions of Expressions. The native source and exact relationships remain reachable through the composed form.

A QL-shaped shared working space lets an agent investigate and organise the selected corpus with the person. It carries the question, frame, exact members/passages, provisional assignments, connections, alternatives and outputs. It is the working construction over the source field, not a duplicate corpus, a hidden prompt-only graph or a new agent framework.

What is made returns: native constellations, contextual memberships and deliberately authored QL relationships enrich the Wiki; Expressions and artifacts become discoverable objects with source/derivation. A generated explanation is not independent corroboration merely because it re-enters the corpus.

### 3.1 Sources, membership and contextual roles

Carry native subject/source owner/ref and revision, exact selector or occurrence, constellation identity/revision, contextual membership and role, chosen frame/form/shape binding and basis. Preserve whole identity through compact/expanded views and nested/composite membership. A whole with several roles is not automatically a set of pairwise assertions.

A working construction may reference a document, passage, media item, existing native subject or another constellation. Define reuse versus revision-bound reuse versus deliberate variant using current native revision semantics. The same source participates in several wholes without reminting it; a composition-instance override does not change all uses of the native whole.

### 3.2 Structural operations and interpretive standing

Expose native form selection, member/role assignment and revision, composition/expansion and formal validation. Retain actual canonical shape/address/derivation references where selected. Preserve authored layout as presentation even when it departs from a canonical form; do not assert that arbitrary positions satisfy a QL binding.

Distinguish a selected canonical grammar from a claim that this corpus has been shown to instantiate it. An agent may propose an interpretation and supply reasons/evidence. Formal tests validate structural rules; they do not certify historical, philosophical or empirical truth. Existing `QlReading`/provenance/result-class semantics remain; no "accepted" flag is invented to conceal these distinctions.

### 3.3 Read and write operations, not read-only views

Bind the following meanings to actual owner Actions: create/open/resume a working constellation; add/remove a selected member; assign/reassign a contextual role; connect/reconnect/type/annotate a relation; inspect source support and frame; compare a variant; save native constellation work; save presentation; return intended knowledge differences; find and reopen the result.

QL owns formal meaning and operations. AIKit's native Wiki/constellation owner owns the recorded knowledge relationships it exposes. Source edits go to Central or the actual source owner. O:I owns Expression/Scene/Edition and Palace composition over native refs. A missing write capability is implemented at its owner and joined through the adapter; the UI must not become the hidden semantic writer.

Reversible presentation edits proceed within granted bounds. Intentional semantic/source mutation is a named Action with revision and authority checks. The UX makes its effect clear without turning each gesture into a governance form. A preview is not a saved relationship; receipt/readback distinguishes saved native work.

Operate on the same authored and source-backed relations. Preserve influence/opposition/recurrence/causation, temporal order, evidence and standing as distinct where the native model supports them. ### M3′ — real Scene composition

Compose selected constellations, source passages, text/media, framing and transitions into actual O:I Expression Scene refs. Scene sequence changes do not change source identity or manufacture Wiki links. Preserve deliberate presentation, current source basis, and an explicit path to the live 3:3 reading.

### M4′ — situation

Situate the same construction in relevant world/place/occasion facets and preserve their native identity, temporal qualification and evidence. Missing geographic/astronomical facets do not block ordinary constellation work or cause invented coordinates. Consume existing accepted producers rather than reopening their mathematics.

### M5′ — Palace, integration and Return

Compose native constellations, Expressions, Scene/Journey refs, media and sources into an inhabitable whole for inquiry, memory and pedagogy. Reuse the existing Stage and persistence. Return a knowledge difference or new artifact through its actual owner, making it discoverable again in M0′/Wiki. This is the practical M5′→M0′ closure, not a decorative export button.

## 5. Shared QL-shaped agent staging

The actual situated Technè/Epii agent operates the same working construction as the human through existing Agency, AIKit context/skills/session and `TechneReading`/`DisclosureSession` contracts. Preserve Guardian versus Anima versus Aletheia-Technè distinctions from the dual-reading lock. This amendment creates no new roster or runtime.

Required shared state: inquiry/question; selected frame; exact selected and admitted members/passages; working constellation revision; contextual assignments and proposed/committed connections; source basis; alternative constructions; actual context disclosed for the current act; available native Actions; current Expression/Scene/selection; attributable output and continuation.

The person can directly alter a member, role or relation while the agent works. The next operation checks that current working basis. Stale proposals are held, rebased or retained as alternatives; they cannot overwrite newer human edits. Selection alone does not disclose protected source. A chat transcript or list of injected documents is not the shared structured state.

A useful first agent act is: inspect selected passages → choose or apply an explicit frame → propose assignments/relationships with reasons → express them in the actual field → receive a human edit → continue from it → save/return the intended bounded result. Hold/interrupt/continue preserves meaningful work and actual Activity/Return identity. Direct activity need not acquire false Factory Run ancestry.

## 6. Return and currentness

Record exact whole/member/role structure and intended typed QL relationships with frame, actor/act, source revisions, support and standing. A QL relation is distinguishable from a Markdown source occurrence, tag membership and visual connection. Native indexing makes the result searchable/filterable without creating another graph database.

Persisted Expressions and artifacts retain derivation. A later agent may reuse them, but repeated generation from one source is not additional independent evidence. Legitimate graph cycles remain possible while expansion and derivation/re-ingestion loops are bounded and honest.

Multi-owner saves expose per-owner outcomes and receipts. If the Expression save succeeds but a semantic relation write fails, preserve the working result and retry the missing effect without duplicate outputs. Do not claim a distributed transaction or complete Return.

External source changes identify affected interpretations and bindings. Stable refs and unrelated authored placement survive. Historical/pinned readings remain inspectable; current work offers deliberate rebase. Hiding an overlay, retracting a relation, changing membership, creating a variant and deleting source remain different operations.
