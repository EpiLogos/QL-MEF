# Matrix F — source-specific findings that alter R2

## F1 — O:I already anticipates the meeting with Epi

`O:I/docs/ARCHITECTURE.md` explicitly says its Self/Other relation is the architectural point where O:I can later meet Epi-Logos as a distributed human-agent field. R2 therefore should treat Epi as a planned deep instantiation/partner of the parent relation, not an accidental legacy workload.

## F2 — O:I Objective Internality is intentionally non-exhaustive

`OBJECTIVE-CO-INTERNALITY.md` explicitly refuses to make a theory of consciousness and records objective conditions of possible internal update. This creates legitimate space for Epi/Nara to model richer human internality while keeping the same epistemic modesty.

## F3 — Encounter deliberately stops before uptake

O:I says `Encounter ≠ subjective experience`. Nara's activity/identity system needs an objective bridge from presentation to later retained/actionable difference. `Uptake` is therefore a real disclosed gap, not an invented social feature.

## F4 — Central deliberately refuses a universal profile schema

Central's source law is a feature, not a missing implementation. Nara should be a structured consumer/interpreter of selected personal source, not the schema Central forgot to implement.

## F5 — Nara already contains a source/inference/promotion constitution

The M4 architecture gives stable identity, current condition, activity, composed state and review-gated promotion distinct places. This is the strongest evidence for lifting human-internality abstractions above current Nara implementation bodies.

## F6 — Factory already supplies many candidate general primitives

Factory's canonical primitive relations cover Project, Context, Run, RunMap, Agent, Agency, Artifact, Claim, Evidence, Decision, Candidate, HumanRequest, Projection and Recognition. Epi should reuse these where it is actually doing development/review rather than creating private Epii synonyms.

## F7 — AIKit Context is the generic inhabitation seam

AIKit's architecture defines Context as scoped effective operational reality and separates declarative Profile from effective view and target Projection. Epi can be deeply context-aware without redefining generic Context.

## F8 — Workcell must stay below human/semantic internality

Workcell explicitly materialises the Operative World and refuses to redefine Project, Context, Agent, Agency or Candidate. The same boundary should apply to Epi graph/audio/cymatic/personal-state providers.

## F9 — O:I WorldPresentation is an external presentation primitive, not the Epi app

The developmental Explore contract lets a projected O:I world carry authored component/Surface composition while source ownership remains native. This is a strong future way to publish Epi worlds/projections, but it must not be confused with M′ Pratibimba or the local Epi 0/1 parent application.

## F10 — current O:I docs contain one live nomenclature drift

At current accepted O:I main, `docs/CANONICAL-PRODUCT-FIELD.md` correctly uses **Actuation** for P1, while `docs/ARCHITECTURE.md` still contains an older functional-field row labelled **Agent Runtime**. The matrix treats Actuation/current product ownership as authoritative and records the Architecture row as stale wording rather than a second product boundary.

# Final cross-document judgment

The matrix supports the final-pass architecture strongly.

The deep relation is not:

```text
old Epi stack → new O:I replacements
```

It is:

```text
O:I
  objective operative internality of technological/human-agent worlds
  + whole-level co-internal relation grammar
                    │
                    ▼
Epi foundation
  explicit Bimba/Pratibimba address, instrument, shared-state,
  human-internality, domain-bridge, privacy and return contracts
                    │
                    ▼
M0′–M5′
  six full purpose-bearing lived instruments / canonical Epi agents
                    │
                    ▼
Epi-Logos 0/1 whole
  human/cosmic internality made interactable
                    │
                    ▼ selective externalisation
O:I Projection / Explore / SharedField
  co-internal relation with other humans, Agents and worlds
```

The largest architecture gap exposed by this work is therefore **not missing generic infrastructure**. It is the absence of an explicit **Epi foundation layer** naming the primitive relations that already exist implicitly across Bimba, the M′ instruments and especially Nara.

That gap plausibly explains a significant amount of earlier implementation drift: domain-specific code was repeatedly asked to carry foundational semantics that had never been stabilised as first-class contracts.

R2 can now close only after human review of this matrix and incorporation of any corrections into the living machine maps.
