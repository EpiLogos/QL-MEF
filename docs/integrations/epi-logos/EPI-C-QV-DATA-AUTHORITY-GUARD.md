# `qv_data.c` authority guard

**Status:** migration/source-provenance guard  
**Applies to:** `vendor/epi-kernel/reference/src/qv_data.c` and historical copies of the same projection  
**Frozen reference:** `EpiLogos/Epi-Logos-C-Experiments@daa660cbc1b8c5da83828698665a753852cb0287`

## Determination

`qv_data.c` is retained as **historical implementation / managed-projection evidence**. It is **not a semantic authority** for QL coordinate-family meanings, Thought-family vocabulary, or direct/prime (conjugate) interpretation.

Inspection of the historical body has exposed semantic drift in descriptive payloads in this file. In particular, its compact T-family labels do not determine the authored T/T′ Thought system. Agents performing kernel migration, refraction work, documentation recovery or Epi integration must therefore keep two questions separate:

```text
What exact values / structures did this historical C projection contain?

What do the coordinates actually mean in the authored Epi / QL system?
```

The first can use `qv_data.c` as frozen evidence. The second cannot.

## Migration rule

When `qv_data.c` contributes to a migration or parity claim:

1. preserve the frozen bytes and source identity unchanged;
2. cite it as implementation/projection evidence only;
3. establish separate provenance for any value promoted as authored/canonical data;
4. establish separate authored/developed authority for any coordinate label or semantic interpretation;
5. record disagreement rather than reconciling semantic drift by invention;
6. never use the QV descriptive payload as a fallback vocabulary when stronger coordinate-family sources exist.

A numerical/table value from QV may still become useful evidence where its generator, source chain or independent authored authority is recovered. That case promotes the **separately proven value relation**, not `qv_data.c` as a whole into semantic authority.

The vendor reference is deliberately unchanged because parity and provenance require an exact historical specimen. Quarantining its authority is therefore a documentation/source-reading operation, not a rewrite of the oracle.
