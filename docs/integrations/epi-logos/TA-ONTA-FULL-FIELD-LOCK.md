Ta-Onta specifies Epi as an internal agent world: what its objects mean, how a situation is constituted, which powers can be used, how an act is composed, what is encountered, and what returns into useful knowledge and praxis. Its SDK/API, manual, agent definitions, Skills/Methods and surface contracts express one specification over the native O:I substrate.

The owner approved the complete in-chat recovery, with the corrections recorded here. Full specification precedes implementation slicing. Every already-defined position below remains in scope; root-level capabilities and the deeper M field are not replaced by these 36 records. Runtime bindings and readiness must be checked against current implementations. This planning table makes no claim that all rows are already implemented.

The historical source strata and current S′ organs are related but different views. The old S4′ children carried the same six organs that now constitute the **S′ whole**. Preserve their agent-facing functions as composition interfaces; do not instantiate a second Khora/Hen/Pleroma/Chronos/Anima/Aletheia tree under current Anima. The `historical:` prefix below qualifies source locators, not new kernel coordinates. Current organ names remain exactly S0′–S5′.
