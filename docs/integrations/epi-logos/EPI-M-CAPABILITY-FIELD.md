## What this layer is

The Ta-Onta 6 × 6 field asks what each M-domain must become through each S′ coordinate so an Agent inhabits Epi. This layer starts instead from the **36 real M-domain capabilities** already recovered and keeps their full operational relation visible:

```text
capability / for what
→ M determination
→ M′ lived instrument
→ clean S0′…S5′ Ta-Onta composition
→ current native O:I mechanics / evidence
→ Epii-on-X developmental relation
→ returned difference
→ Recognition by the authority owning target ground
```

A live generic mechanic does not prove the Epi composition. An authored Epii-on-X development law does not prove its development pipeline is implemented. Those standings remain independent in the machine carrier.
