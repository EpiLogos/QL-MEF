```text

S1′ Hen
S2′ Pleroma
```

## Chronos lock: Kerykeion, collective NOW, Earth/world referent

Chronos is not a generic timestamp service. The current Epi sources distinguish quantitative Chronos from qualitative Kairos and make **Kerykeion first-class** to the latter: planetary position, decan/tattva and aspect condition qualify the present cosmic state. The current M-stack source specifies a shared `world_clock` carrying harmonic tick plus Sun/Moon/planetary state and Kerykeion version.

O:I already has the hosted substrate: SpaceTimeDB SharedField is live across browser/site, desktop-shared and structured-Agent application readings. Therefore M3 collective NOW is not a hypothetical service. The Epi relation is:

```text
M1 harmonic tick
      ↓
M2 Kerykeion cosmic qualification
      ↓
M3 shared Earth-relative world_clock / collective NOW
      ↓
M4 natal + Q_transit + DAY/NOW + episodes
```

The shared Earth/world referent is presently `DERIVED-CURRENT-ARCHITECTURE`: the relation is source-generated, but this matrix does not invent a canonical `EarthRef` if no such source object has yet been ratified. SpaceTimeDB hosts state; it does not own Epi semantic identity.
