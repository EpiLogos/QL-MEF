The reason is functional. The generic mechanics of those functions have since matured into Central, Actuation, AIKit, Factory, Workcell, QL-MEF and O:I SharedField. Ta-Onta therefore becomes stronger by composing those native capabilities rather than reproducing them.

### Khora — Epi cradle

Khora is not session metadata. Historically it was the bootstrap spine reading continuation, Agent rules, human ground, paradigm, memory, NOW and tools before the rest of Ta-Onta acted. Current Khora composes entry conditions from Central ground, Actuation actor/authority, AIKit Context/SessionSpace/composition, Workcell environment and Bimba/QL source state.

Hen's purpose is not “files.” It makes Bimba/Pratibimba inhabitable as coordinates, forms, source standings, linked artifacts and Wiki/graph neighbourhoods. AIKit SemanticWiki/Living Knowledge owns generic Wiki intelligence; Hen is the Epi semantic composition ensuring those objects participate in Bimba/M/M′.

Pleroma is the Agent's field of powers. AIKit owns Capability/Action/Skill/Method/Context/model/harness/Component/Surface composition; Workcell supplies material providers; Actuation supplies authority. Pleroma composes these as the operative Epi body required by the current M/Context-Frame act.

### Chronos — temporal/cosmic body

Chronos preserves distinct registers:

```text

M2 Kerykeion / Kairos cosmic condition
M3 world-clock / collective NOW
```

**Kerykeion is first-class.** Current M4 depth source distinguishes Chronos quantitative time from Kairos qualitative time and explicitly binds Kairos to Kerykeion: planetary positions, decanic/tattvic state and aspect-density qualify the current M2→M3→M4 field.

O:I already has a live SpaceTimeDB SharedField path across hosted/browser, desktop-shared and structured-Agent readings. The collective NOW therefore does not need a hypothetical new transport.
