The following are no longer open research questions for this programme:

```text
Ta-Onta = S′ whole

S0′ Khora
S1′ Hen
S2′ Pleroma
S3′ Chronos
S4′ Anima

```

Same-index S↔S′ relations are structural affinities, not exclusive implementation ownership. The 36 recovered `M*P-*` identities are the standing capability field. Their provider, S′ participation, evidence and readiness may evolve from returned implementation reality without reopening their identities.

## Readiness meanings

- `ALREADY-REAL` — the full capability is demonstrably present in the current Epi/O:I composition.
- `READY-TO-COMPOSE` — required generic native mechanics are present; the remaining work is Epi composition/integration and proof.
- `EPI-GAP` — an Epi-specific provider, instrument or adapter still has to be built before the capability can be proved whole.
- `NATIVE-GAP` — a required generic native-owner capability is missing.
- `RESEARCH-ONLY` — not yet an implementation target. Use principally for unimplemented Epii-on-X developmental pipelines, not ordinary capability rows.

This ledger is deliberately conservative: a live generic substrate does not by itself make an Epi capability `ALREADY-REAL`.
