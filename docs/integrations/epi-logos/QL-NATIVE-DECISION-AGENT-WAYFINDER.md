## Determination boundary and loop

Each field keeps its epistemic origin: observed, derived, learned or unresolved. Validation is an additional admission event retaining the original learned/observed origin, not a replacement label. Refused proposals remain visible with reasons. A provider probability is model evidence, never proof of source support.

Before any inference:
1. Parse explicit coordinates, refs and typed native state.
2. Resolve direct/conjugate faces and local/absolute positions.
3. Compute applicable conjugate, complement and Möbius relations.
4. Classify positional traversals with every legitimate A/B/C overlap.
5. Complete available D1/D2/D3, shapes and constellations.
6. Compute supplied-state Context-Frame and harmonic consequences.
7. Construct only unresolved, semantically relevant heads.

Zero heads means zero model calls. For example, explicit L2′ observes the lens; its face/position and a supplied rotation are derived. A known traversal's family candidates and pitch/ratio are derived. Ordinary prose's relevant faculty or supported Context Frame may require learned selection. An impossible combination is refused, never silently repaired.

The common loop is encounter → owner-native event projection → deterministic completion → optional unresolved semantic decision → kernel validation → exact native operation → formal/harmonic readout → continuation → attributable Activity/Return. Epi mode alone never triggers inference.

## Reproducible corpus and research

Required families:
- Face/coordinates: direct/conjugate, same-position conjugation, complement, Möbius partner, rotations, local/absolute.
- A/B/C: canonical/reversed pairs, genuine overlap, noncanonical cases and pair indices.
- Completion: D1, left/right D2, D3, missing side and contradictions.
- Geometry: supported 1–12 folds, two/threefold compression, fourfold, 4×4, 4×4×4, 6×6, relational sixfold, eighteenfold, 10×10 Second-Spanda.
- MEF: all twelve lenses, Day/Night, Articulation/Encounter/Becoming, all seven CFs, Name/Power, inner-four/outer-two and rotation invariants.
- Harmonics: deterministic anchors, deltas, squares, completion, CF/modal and ratios.
- Semantic routing: faculty/operation, no warranted formal operation, missing source, multiple live interpretations, correct tool with wrong authority or incomplete input.

Counterfactuals distinguish wrong face, family, index, CF, complement, unsupported semantics and harmonically plausible but structurally impossible results. Split by structural/template families. Hold out wording, combinations, reversal, ambiguity, long context and real unused traces. Keep verifier answers out of acting context.

Sequence: G0 deterministic-only; G1 untouched GLiNER; K0 current Kev; optional available/authorised Jev comparison; G2 improved schemas; G3 first LoRA only after frozen holdout; G4+ autoresearch. A QL-native checkpoint must improve held-out discrimination, not merely produce QL vocabulary.

State denominators, zero-denominator/unsupported metrics and test selection honestly.

Vary descriptions/instructions, representation, family proportions, negatives, LoRA rank/rate/epochs/batches, thresholds, packaging, constraints and evidence strategy. Primary metric is held-out exact/set performance. Hard gates: zero impossible operative results, deterministic bypass unchanged, frozen ambiguity and missing-evidence thresholds.
