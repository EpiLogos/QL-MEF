**Standing:** owner-ratified conceptual architecture, 2026-09-16.  
**Scope:** clarifies the relation among the existing M′ deep-product programme, the O:I Expression world, Research Canvas disclosure instruments, Ta-Onta S′, canonical Guardians and the #65 convergence/experience campaign.

That Wayfinder remains valid for `ql.techne/v1`, native ownership, shared subject/selection, `TechneAdapter`, Research Canvas migration, Scene/Expression reuse, UI parity, lifecycle and parallel implementation where not explicitly corrected here.

There is **one M′ field with two primary application readings**.


```text

```

No M6 or M7 is introduced. The non-numbered 0/1 parent remains the containing Epi relation.

# I — ORTHOGONAL SIXFOLDS MUST NOT COLLAPSE

## 1. L5 offices are not the six instruments

The canonical L5 / Para Vāk articulation remains:

```text
L5-0 Syntax
L5-1 Root
L5-2 Harmonics
L5-3 Geometry
L5-4 Meta Epistemic Framework
L5-5 Techne
```

The six deep instruments are **not** mapped to these six offices by cardinality.

All six deep instruments are acts of **L5-5 Technē**: creation/generative use through the whole prior QL articulation. Syntax, Root, Harmonics, Geometry, MEF, Context Frames and Vāk can all participate inside any instrument reading.

The new M′ mapping is therefore orthogonal to the L5-office projection:

```text
L5-5 Technē
    = generative office of the whole QL articulation

M0′…M5′ Technē instruments
    = six deep application coordinates through which that generative office
      becomes professionally inhabitable
```

This distinction preserves the current QL kernel architecture while giving the deep instrument suite its exact Epi coordinate form.


The deep Technē surface assigned below is a **professional application projection of M_i′**, not an assertion that the same-index S product exclusively implements that surface. Implementation remains many-to-many and native owners keep their domains.

## 3. The two Ta-Onta axes remain distinct from M′

The ratified M×S′ matrix already contains six M-domain readings inside each Ta-Onta organ. This gives the exact agentic structure needed by the two application cuts without inventing a second Agent framework.

Two especially important rows are:


# III — THE 4:2 TECHNĒ READING

## 6. M0′ — Project / Wiki / Graph: ground and address

**Professional office:** locate, traverse and establish the existing working world from which deeper construction begins.

This is not a new Projects database or application.

Its body is the already-existing relation:

```text

    + Work Projects / ProjectCentral
    + project/root/shared WikiSpaces
    + AIKit ProjectMap / SemanticWiki / Search / KnowledgeRoute
    + optional QL constellation/refraction overlays
        ↓
Project / Wiki / Graph Technē aperture
```

The current AIKit law already gives the required presentation grammar:

```text
one relation/selection state
    ├─ LIST
    ├─ TREE
    └─ GRAPH
```

The same visual/interaction family should govern:

```text
M0′ Project/Technē graph        deep navigation/authoring
Expression M0 companion        bounded local-whole/source depth
SharedField/Wiki projection    governed audience projection
```

Same refs, same native Wiki/ProjectMap relation identities, different aperture and disclosure policy.

**Development consequence:** no separate Projects lane should build a replacement tree, graph store, search engine or constellation ontology. The work is convergence of Central/ProjectCentral + AIKit KnowledgeNavigation + existing O:I Wiki/graph projection into the deep M0′ instrument.

## 7. M1′ — Canvas / Constellation: constructive determination

**Professional office:** directly construct, arrange, bound, annotate and relate the selected field.

Canvas consumes semantic identity from Wiki/ProjectMap and structural intelligence from QL constellation/geometry where warranted. It owns the **authored spatial arrangement and professional interaction body**, not a second ontology.

Required mature acts include:

- selection/lasso/multi-select;
- drag/resize/group/frame/layer/z-order;
- align/distribute/snap/guides;
- authored edge creation/reconnect/type/evidence/standing;
- relation proposal → reviewed/native relation Action where applicable;
- constellation membership composition against the real constellation owner;
- semantic zoom and bounded neighbour expansion;
- source/provenance inspection;
- saved presentation Views without treating layout as semantic truth.

QL geometry can propose lawful layouts/shape disclosures while preserving authored arrangement as presentation state.

## 8. M2′ — Relation Field / Timeline: becoming and efficient relation

**Professional office:** disclose how the field moves, changes, causes, recurs, resonates, opposes, inherits and transforms.

Timeline is its strongest ordinary visual projection but **time does not exhaust the office**.

The existing Research Canvas ontology must be preserved:

- historically datable instance != trans-temporal Archetype/Dynamic/PsychoidOperator;
- `INSTANTIATES` / `ECHOES` != historical chronology;
- `CAUSES`, `INFLUENCES`, `OPPOSES`, `INHERITS`, `TRANSFORMS_INTO` retain distinct meanings;
- fact, myth, allegation, disputed claim and interpretation remain evidence/standing distinctions rather than visual categories inferred from prose.

The M2 instrument can therefore move among projections such as:

```text
temporal chronology
relation field
causal chain
recurrence / echo
phase / cycle
activity / Run / NOW concurrency
```

without manufacturing dates for relations that are not chronological.

Central DAY/NOW, AgentSession, Factory Runs/activity/evidence and historical time remain distinct temporal objects. Occurrence, receipt and validity must not collapse to one timestamp.

## 9. M3′ — Journey / Scenes: formal mediation between 4:2 and 3:3

**Professional office:** turn selected researched determinations into an authored traversal capable of becoming lived Expression.

M3 is the strongest formal hinge between the two cuts:

```text
Project / Canvas / Relation / Place selections
    + source / text / media / narration
    + saved apertures / constellation state
        ↓
Journey composition
        ↓

        ↓
3:3 living Expression experience
```

The existing persistence decision remains locked:

```text

    -> real Expression Scene refs
    -> optional Scene frame: time + place + subjects + source/media refs
```

No second Journey scene ontology is introduced merely to preserve historical Research Canvas implementation.

M3 authors sequence, pacing, relation, framing and transition; the Expression world remains scene/presentation owner.

## 10. M4′ — Places / World: situated whole and Earth relation

**Professional office:** situate the field in the concrete spatial/world context in which its relations hold.

The current map/street/globe work remains the Earth-facing interaction body, but the office is broader than geographic pins.

It can join:


The solar/planetary depth is not a decorative feature bolted onto the globe. It is the wider reference-frame depth of this M4 world instrument, consuming current accepted M2/M3 producers rather than recomputing astronomy/QL in the UI.

The intended scale relation is:

```text

        ↓
```

## 11. M5′ — Palace / integral articulation: inhabitable whole and Return

**Professional office:** make the articulated field inhabitable, memorable, teachable and reflexively available as a whole.

Palace now has a precise reason to exist: it is the explicit deep objectification of the otherwise ambient M5 articulation/pedagogy/recognition pole.
