## 0. The purpose of the 5/0 relation

Bimba supplies articulated ground: coordinates, properties, relations, source forms, Wiki constellations and the full Vāk language. Epii enters that ground, investigates, composes an act, explains and returns what happened. Ta-Onta specifies the relation as an inhabitable agent world. Nara is the particular person, body, history and present concern through which that activity has significance.

The world develops both what it knows and how it knows how to act. The personal Return develops understanding/practice; the operative Return develops the system's ability to accompany, investigate and express that process. A successful path can become a recognised name and subsequently a reusable function, while its original evidence and expansion remain available.

The full M0 language is **109 source entries**, including mathematical, self/other, generative, contextual and operative depth. The compact six-operation × six-horizon field is one articulated part of that language. Count neither an implementation enum nor the seven CFs as the whole Vāk corpus. Preserve the source exactness and all relations, including the meanings borne by punctuation and enacted motion.

### 3.1 Required lifecycle

1. Human intent/current undertaking enters an actual Central-owned NOW, with subject, source and any Factory Run relation.
2. The agent produces only useful T/T′ contributions during work: question, evidence, important choice, difference, blocker or returned insight. Each points to the work/output it concerns.
3. The human can redirect, disagree, qualify or accept. Those interventions remain attributable source, not silently rewritten agent interpretation.
4. Consumption compares the reports with retrieval, executions, actual outputs and human responses. It produces source-linked learning context, Wiki knowledge/relations, evaluations, improved Skills/usage patterns, recognised named praxis or an unresolved question that genuinely needs to continue.
5. Record what consumed the working material, what was retained and the source basis. Redundant T/T′ work leaves the active context; retention/archive/deletion follows native source policy and preserves the necessary evidence. Do not accumulate unconsumed commentary as an end in itself.
6. Subsequent agency retrieves the useful result and can reopen its evidence when necessary. Original occasion and later reinterpretation remain distinguishable.

Use existing Central NOW/source operations, AIKit Wiki/Knowledge/Living Knowledge and Factory RunThoughtField for commissioned work. Direct non-Factory thought stays possible through the relevant source/agency owners. This cognitive lifecycle does not create another session, Run or memory store.

### 3.2 Pithy reports and calibration

The expandable backing retains details, not a verbose obligatory narrative in the conversation. Test whether a reported source was actually read, whether claimed work produced the stated output, whether a comparison included the required subjects, whether uncertainty matched later findings and whether the human's actual concern was answered.
