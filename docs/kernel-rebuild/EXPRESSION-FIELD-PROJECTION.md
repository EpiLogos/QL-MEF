# QL / M / Nara projection into the O:I Expression Field

**Standing:** owner-approved integration direction, 14 September 2026. This is a consumer/projection contract over the accepted K8/K9/K10/AW work. It does not reopen those implementations, create a new renderer, redefine M/M′ or transfer ownership from O:I, Wiki, Central, AIKit, Actuation or Factory.

## 1. Relation to the accepted kernel programme

Accepted current truths remain:

- M0′ is the actual Bimba/source world;
- M1′–M3′ are the accepted formal/topological, spectral/material and form/clock instruments over one event;
- M4′ is the full Nara lived/personal field built on the accepted Personal receiver;
- M5′ is canonical Epii;
- K8 owns the accepted continuous M1/M2/M3 material/audio runtime;
- K10 owns Nara/M4 truth and protected personal reception;
- O:I owns the reusable Expression Stage/renderer/presentation body;
- K9's focused instrument remains a valid privileged composition, but left Bimba and right Epii are **available apertures**, not compulsory permanent chrome.

The new relation is that O:I Expressions become the general living presentation body through which those already-owned truths can be composed, focused, taught and projected.

## 2. Coordinate as locus, not page ontology

An M coordinate must not become an isolated application or canonical page file. A coordinate supplies a **locus of determination** from which a whole-field Expression can be derived.

```text
M coordinate / subject
        ↓
source + current readings + relations
        ↓
presentation grammar
        ↓
Expression state of the whole
```

The derived Expression remains attributable to the source coordinate and the exact input revisions. Authored/pedagogical Expressions may refine the presentation without becoming the coordinate's semantic owner.

Therefore:

```text
coordinate != Expression
Expression != source truth
presentation relation != canonical M relation by visual resemblance
```

## 3. M0 / Wiki / Bimba projection

M0's Bimba/Wiki world supplies semantic subjects and relations. A bounded local whole can be projected into an Expression through stable refs:

```text
selected coordinate / Wiki subject
  → bounded local whole
  → typed relation/source/property readings
  → optional QL constellation / harmonic / glyph grammar
  → O:I Expression entities and relation presentation
```

QL pair, triad, whole, direct/conjugate and harmonic structures may provide stable layout or glyph grammars where source-backed. They do not infer missing semantic edges or create another graph store.

The same adapter can consume ordinary Wiki/knowledge subjects where no deep M reading exists. QL specialisation is additive rather than a correctness prerequisite.

Required preservation:

- exact source/coordinate/registry revision;
- direct/conjugate identity where applicable;
- typed relation IDs and standing;
- rich/compact/quintessential/derived property standing;
- unresolved or unavailable relations remain unavailable;
- pin/follow/recentre does not mutate canonical graph identity;
- source/Action invocation stays with the owner.

## 4. M1–M5 focused presentation grammar

The Expression Field can foreground each M determination without separating the six instruments into applications.

### M1 — topology / harmonic carrier

Project accepted topology, phase, winding, carrier and harmonic state into geometry, trajectory, morph/phase and relational organisation. The current point-cloud toroidal/poloidal system is a material presentation target; accepted M1 state remains the numerical/formal owner.

Manual/creative Expression controls remain legitimate when not following live M1, or when an explicit follow/release/override state says so.

### M2 — resonance / material / symbolic qualification

Project accepted M2 music, resonance, colour, material, correspondence and symbolic worlds into the shared resonant/material medium. The visual cymatic resonator is a presentation/physical-approximation body; K8/native M2 remains the accepted musical/material state and audio owner.

**Spatial chakra centres are not cymatic resonant stations.** A centre may receive or relate to one or many resonant conditions. The seven-station presentation must not redefine seven Nara centres.

### M3 — form / clock / transcription

Project accepted M3 constituent identities, apertures, clock centre, independent inscription/lensing phases, glyph/transcription, pose/fold/Tarot/codon forms into stable Expression entities/scenes.

The clock can therefore be presented as an authored arrangement of many stable constituents. Assemble/explode/reassemble, phase changes and 360/720 relations remain presentation/operation over the same canonical constituent identities; no bespoke Clock application is required.

### M4 — Nara

Bind the protected accepted Nara state to live session-local Expression rendering:

- seven independently constituted receiving centres;
- EarthBody distinct;
- exact M1/M2/M3 contribution refs;
- identity/transit/activity composition;
- relevant M4 branch state and protected source refs;
- consent/disclosure/lifecycle preserved.

Portable Expression projection contains safe refs/cues/host artifacts, not raw identity, journal, bioquaternion or centre bodies.

### M5 — Epii

Epii remains the same canonical Agent/AgentSession. It can inspect and operate Expressions through O:I's agent-native Expression operations and existing native Actions. It may compose pedagogical Expressions, focus subjects, arrange scenes, invoke permitted domain operations and return evidence without becoming renderer or source owner.

## 7. Agent-native and Action-led surface law

The M4′/focused instrument surface should no longer be understood as a fixed UI arrangement. It is a composable Expression application over native subjects.

A capable Agent must be able to:

- inspect current Expression/scene/entity bindings;
- resolve the selected M/Bimba/Nara subject;
- project a bounded local whole;
- apply an available QL layout/constellation grammar;
- create/reorder pedagogical scenes;
- bind/release live M1/M2/M3/Nara following;
- inspect source/currentness;
- invoke canonical domain Actions through actual authority;
- capture/embed/project through O:I operations.

The exact Expression application contract belongs to O:I. QL supplies subject/readings/layout grammars/domain Actions; it does not introduce a parallel Expression API.

## 8. Human presentation law

The default focused relation is the living Expression.

Bimba/search/source and Epii/Agent are summonable apertures which may be panel, overlay, split, full or detached. Their placement is presentation state; source and AgentSession identity remains canonical.

This refines the earlier K9 triptych wording:

```text

but:
Expression as resting/foreground world
  + Bimba/source aperture when summoned
  + Epii/Agent aperture when summoned
  + native writing/files/explainer/Studio depths as required
```

The existing K9 host portals remain usable mechanics; activation should not require all three regions to be visible simultaneously.

## 9. Shared/page relation

QL produces no new page or publishing system. O:I may embed a live/captured Expression inside Beings/Things, HTML forms or WorldPresentation. A coordinate-derived presentation retains its M/source refs and standing.

SharedField publication applies O:I Projection/audience rules. Protected Nara values and unavailable source relations are never exported merely because their local visual representation existed.
