## What the implemented value layer does

`ql_mef::property::PropertyField` borrows the existing `MRegistry`; only that
registry supplies node and structural-relation identity. Source-qualified
Definitions retain all original property-spec fields and require separately
bound applicability. Historical `coordinate_home` is not a wildcard scope.
Definition identity, revision, aliases, units, domains and embedding dimensions
remain explicit. Ambiguous handles return plural candidates rather than guess.

A rich assertion is independently identified, including when several values
qualify the same relation. Source, producer, actual result handle, standing,
warrant, validity interval, previous revision, Recognition and rollback ancestry
are retained. Expected-revision changes append; they do not overwrite earlier
assertions. Exact operation replay returns its original receipt. A reused
operation ID with changed content is refused. Source or permission refusal
leaves the in-process field unchanged and is not automatically retried.

The local six offices remain distinct: native subject (#0), source property
identity (#1), rich assertion (#2), bounded exact compact/expand (#3), explicitly
named quintessential producer/result (#4), and source-qualified graph-derived
reading (#5). A `q_4_` prefix does not select an office. The value layer does not
invent a universal q_* synthesis algorithm, treat old QV bake as one, or run GDS.
Graph-derived records retain their graph/algorithm versions, parameters and
included/excluded scope; reviewing one does not make it an intrinsic property.

`NativePropertyAdmission` is an interface to the existing native source and
authority owner, not a new grant store. It must observe sources and evaluate the
complete operation. Current and historical source use are distinguishable.
Disclosure also goes through the owner, including protected definitions and
assertions. The controlled test implementation is not production authority.

## Actual boundary of this increment

These calls perform real validation, in-process graph-value mutation, revisioned
readback, Recognition transition, rollback and compact expansion. They do not
write a remote graph, author human files, publish a Wiki, execute a model or
promote canonical C vocabulary. Native persistence/transaction/Actuation/source
transport, complete coordinate-conditioned applicability, QV/bake migration,
actual named synthesis/GDS execution and end-to-end Bimba/Epii reception remain
named work in AW1/#94. A rollback restores an earlier value as a new proposal;
the old Recognition stays attached to the old act rather than approving a new
one implicitly. Historical expansion uses the exact definition revision.

The original 194 definitions are exercised via
`cargo run -p ql-mef --example property_source_check -- <decompressed-source.json>`.
The example invokes define/publish/compact/expand for every node and relationship
specification, and rejects a mismatched value for each. Its exact current-subject
bindings and values are controlled test fixtures, not a claim that the historical
home makes every property applicable to M0. Unit regressions cover negative,
stale, denied, duplicate, ambiguity, independent relation evidence, Review and
rollback cases. Exact-head Actions is the test authority; a written test is not
a passing test. Local container execution was unavailable at authoring time.
