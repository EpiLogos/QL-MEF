operable. Its native body includes the nucleotide and pair field, three matrix
families, codon and I-Ching readings, 384 elementary changes, 472 lawful poses,
Tarot expression, DNA/RNA transcription and the whole 360-degree / 24-backbone /
720-degree clock. The lower-level Rust modules already carrying this work are
retained. Native C now seats their structural counterparts, with explicit
source-coordinate comparisons rather than just agreement between two ports.

The producer can supply Cosmic, Nara's Personal reception and deep M3′ from the
same state. It does not own the desktop, Nara's identity, an agent loop, audio
callbacks or continuous simulation. M0′ is the Bimba map; M5′ is the Epii agent.
They can locate the source objects and invoke the owner-approved M3 Actions
through these same refs. K10 supplies those map and agent operations; K8 owns
the adapter to the already-built point-cloud implementation.

## Identity, source and memory

The unchanged K2 registry supplies every node and relation identity. IDs are
`uint64_t` in C and sixteen lower-case hexadecimal digits in JSON, avoiding
lossy JavaScript-number transport. Source refs retain `-`, `.`, `/`, compound
segments and their exact registered spelling. The registry revision and
separate M3 catalogue revision accompany the handoff.

The catalogue is generated by `scripts/m3-domain.py` using the accepted source
audit. It preserves all 996 M3 node payloads and 4,891 qualified relation
payloads. It is an immutable projection at existing identities, not another
editable Bimba graph. C holds finite IDs, record numbers, qualified relation
properties and source-backed prototype/cell records. Rust exposes the rich
node payloads. Semantic retrieval is performed outside realtime callbacks.

C returned descriptor pointers have immutable static lifetime. Caller-owned
output structures are copied only after validation succeeds. `QL_M3_INVALID`
means invalid input; `QL_M3_GAP` means a valid request has no admitted result.
Neither error writes the output. Native zero IDs mean absent endpoints, not
fabricated coordinates; `255` remains the explicit finite-table sentinel.
The catalogue does not remove qualified duplicate edges or null endpoints.

## Transactional state and handoff

`M3State::new` validates the contract/registry revisions, bounded refs, exact
JSON integers, address, lawful pose, sixteen-lens index, matrix axis and input
identity. An M2 stamp must match the opening event and profile generation.
Duplicate owner-reading roles are rejected. Occurrence time and receipt time
are retained separately; neither is treated as a Day or an agent NOW.

`apply` accepts a bounded batch of up to 64 operations with expected generation,
event, subject, actor/cause refs and occurrence/receipt times. Supported Actions
select a form, change a line, apply a matrix, select a lawful pose or aperture,
move to its reciprocal, advance the clock, transcribe DNA/RNA, or receive
three signed crease readings. Invalid input aborts the batch. A resonance gap
returns `provisional-unchanged` and rolls back earlier operations in that batch.
A successful batch commits one new generation. A replayed/stale command cannot
silently apply twice. Clock or generation overflow is rejected.

Every receipt includes before/after states, the exact command and the same
parent event/subject. The snapshot jointly supplies form/hexagram refs, pair
geometry, matrix axis, pose ordinal, signed angles/velocities, four charges,
orientation seed, EFWA site components, 18-lens aperture state, full clock and
source backbone prototype, DNA/RNA plus plural source translations, native
Tarot/I-Ching readings, qualified matrix source links and input provenance.

Original input generations are not relabelled as fresh observations when an
M3-only operation commits a new state generation. The packet retains those
bases explicitly. A parent coordinator atomically adopts the returned whole
generation; it must not splice fields from different snapshots. Changes to
M2/Personal inputs require a new coherent owner-supplied composition. Opening,
hiding, muting, splitting or deep-opening a surface does not call an M3 state
operation, invent another clock, or reset the subject.

JSON integers in this handoff are bounded to 2^53−1. The lower-level native C
clock separately supports checked full-width `uint64_t` arithmetic. Real-time
continuous interpolation, memory transport, audio scheduling and GPU buffers
are K8 decisions. Float/GPU state cannot overwrite canonical symbolic identity;
canonical changes return through the Rust owner.
