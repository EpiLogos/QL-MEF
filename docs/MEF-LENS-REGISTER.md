# MEF Lens Register — Canonical Reference (L0–L5, L0'–L5')

*Canonical register of the twelve MEF lenses. Source of truth: `epi_logos_coordinate_system.md` and `epi_logos_cheat_sheet.md`. This register exists because lenses were being named without their machinery run — L-numbers used as vibes. A lens named in prose must run its defined machinery.*

---

## 1. The Rules

1. **A lens named must run its machinery.** Naming "L4" without naming and applying its defined sub-slots (Sein, Geworfenheit, Dasein, Zeit, Besorge, Gelassenheit) is not using L4. A lens is its machinery; the name alone is decoration.
2. **The data layer is pre-lens.** Raw ephemeris positions, the I Ching cast record, news items — none of these are a lens. They are the material all lenses refract. "L3 facts" for plain sky data is a category error (committed 2026-08-09, corrected here).
3. **L3 ≠ "mechanical listing."** L3 is **Processual** (Whitehead/Bergson/Lacan). L3' is **Chronological** (Hegel). They are distinct lenses with distinct machinery. A mechanical list is pre-lens enumeration — it is not any lens.
4. **Squares are lens-pairs over position-pairs:** Square A = P0/P5/P0'/P5' (L0↔L5', L5↔L0') · Square B = P1/P4/P1'/P4' (L1↔L4', L4↔L1') · Square C = P2/P3/P2'/P3' (L2↔L3', L3↔L2'). The briefing's Square B (L1·L4·L4'·L1') is the legitimate P1/P4 lens set — its failure mode is execution (machinery not run), not selection.
